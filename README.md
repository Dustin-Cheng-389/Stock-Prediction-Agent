# Stock Prediction Agent

A Python multi-agent stock analysis project that combines market data, technical indicators, company news, and OpenAI-generated analysis into a 30-day research report.

> This is an educational project, not financial advice. Its generated forecasts are experimental and should not be used as the sole basis for investment decisions.

## Features

- Downloads historical price data from Yahoo Finance
- Calculates SMA, EMA, Bollinger Bands, MACD, RSI, and a regression trend
- Retrieves company news from Finnhub
- Filters and summarizes investor-relevant news with OpenAI models
- Produces technical and news-adjusted 30-day price projections
- Writes a text report and includes a separate evaluation workflow

## Requirements

- Python 3.10 or newer
- An OpenAI API key
- A Finnhub API key

## Setup

1. Clone the repository:

   ```bash
   git clone git@github.com:Dustin-Cheng-389/Stock-Prediction-Agent.git
   cd Stock-Prediction-Agent
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

   On Windows, use `.venv\Scripts\activate`.

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Create your local environment file:

   ```bash
   cp .env.example .env
   ```

5. Add your API keys to `.env`:

   ```dotenv
   OPENAI_API_KEY=your_openai_api_key
   FINNHUB_API_KEY=your_finnhub_api_key
   ```

Never commit your real `.env` file.

## Usage

Run the interactive report generator:

```bash
python main.py
```

Enter a stock ticker and the number of news articles to analyze. The program writes the completed report to `final_30_day_report_<TICKER>.txt`.

Run the evaluation workflow with:

```bash
python Evaluation/evaluate_prediction.py
```

## How it works

Two analysis paths feed the final reporter:

1. Historical prices → technical indicators → AI-assisted projection
2. Company news → relevance filtering → investor-focused summaries

The reporter combines both paths into a written outlook and a news-adjusted projection.

## Limitations

- Language-model output is nondeterministic and may be inaccurate.
- A 30-day price list generated by an LLM is not a validated forecasting model.
- Market holidays are not explicitly removed from projected dates.
- API availability, model access, and rate limits may affect results.
